数据管理

移动端

V3.5 已优化手机端导航、卡片布局和阅读区域。可直接用手机浏览器打开 GitHub Pages 地址。

账号与云同步

当前版本采用“GitHub Pages 前端 + Cloudflare Worker 安全代理 + DeepSeek API”架构。API Key 只保存在 Cloudflare Worker 的 Secret 中，不会放进网页代码、localStorage 或导出的学习数据。

学习者信息
本地数据

学习记录保存在当前浏览器的 localStorage 中。

DeepSeek 安全代理

网页端只保存你的 Worker 地址和模型名称，不保存 DeepSeek API Key。Worker 再把请求安全转发给 DeepSeek。

安全提示：不要把 DeepSeek API Key 粘贴到这个网页。请把 Key 设置到 Cloudflare Worker 的 Secret：DEEPSEEK_API_KEY。

跨设备同步

正式云同步需要后端数据库/登录服务；V3.5 先提供 JSON 导入导出，避免强制接入付费服务。

建议

换手机或浏览器前先导出 JSON，之后在新设备导入即可恢复。
